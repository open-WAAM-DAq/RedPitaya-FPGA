The 64 bit lost counters hold the samples (after decimation) that were not
written right before the buffer: words dropped while the next buffer is not
free, the words of the FIFO when it is reset for that reason, and the samples
not written while the block mode waits for a trigger. The value is latched with
the first write request of the buffer, it does not saturate. The first buffer
after a start without the trigger mode reports 0. Channels the board does not
have read 0.

Stream words. Input (32 bit, one per RLE run, or per sample without RLE):
bits 31:24 count, 23:16 N lines, 15:8 count, 7:0 P lines; the word stands for
count + 1 samples (both lanes share one run since the pattern and the RLE take
P and N as one sample). Output (32 bit): bits 31:24 P lines, 23:16 N lines,
7:0 count; with RLE (0x54) the word is played count + 1 clocks, without RLE one
clock. The output buffer ready flags (0x90 bits 7:6) are cleared while the
output DMA is stopped: buffer 1 plays without one, buffer 2 is marked after the
start. The input lost counters count samples as the scope ones do.
